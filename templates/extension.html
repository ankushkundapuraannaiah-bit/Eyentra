Browser capture

Install the local Eyentra screenshot extension.

Click the extension icon, drag over the visible browser area, and the crop is uploaded to your logged-in Eyentra account with a QR code ready to share.

Install in Chrome or Edge

  1. Keep Eyentra running at http://127.0.0.1:5000.
  2. Log in to your Eyentra account in the browser.
  3. Open chrome://extensions or edge://extensions.
  4. Enable Developer mode.
  5. Choose Load unpacked and select photoshare/extension.

How capture works

The extension uses the browser screenshot API for the current tab, crops only your selected rectangle, then posts the image to Eyentra's Python API.
