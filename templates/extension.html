📋 How to Install

1
Download the extension file

Click the Download Extension button above to get the .crx file.

2
Open Chrome Extensions page

In Chrome, go to chrome://extensions or click ⋮ → More Tools → Extensions.

3
Enable Developer Mode

Toggle Developer mode on (top-right of the Extensions page).

4
Drag and drop the .crx file

Drag the downloaded .crx file onto the Extensions page and click Add Extension.

✓
You're all set!

The Eyentra icon will appear in your Chrome toolbar. Click it and log in with your Eyentra account.
