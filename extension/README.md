# Eyentra Capture Extension

Load this folder as an unpacked Chrome or Edge extension.

1. Run Eyentra locally at `http://127.0.0.1:5000`.
2. Log in to Eyentra in the same browser.
3. Open `chrome://extensions` or `edge://extensions`.
4. Enable Developer mode.
5. Click Load unpacked and select this `extension` folder.
6. Click the Eyentra Capture extension icon, drag a region, and release.

The selected region is uploaded to your account and the photo detail page opens with
the generated QR code and share password.
